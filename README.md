# colorsplash-xg-ha

Home Assistant control for the J&J Electronics ColorSplash XG pool light
controller (LPL-XG-CTRL-1) via an ESP32-S3 + LVGL touchscreen bridge that
owns the BLE link and exposes the controller to HA through ESPHome's native
API.

See [`docs/PLAN.md`](docs/PLAN.md) for the project plan, risks, phases, and
issue map.

Status: planning complete, implementation tracked in GitHub issues.
